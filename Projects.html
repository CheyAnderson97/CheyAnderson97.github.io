Project One: Software Testing, Automation & Refactoring

Original Course: CS 320 | Enhancements: Builder Pattern, Centralized Validation, ConcurrentHashMap ($O(1)$ Lookups)

Artifact Overview: Originally developed as a CRUD appointment, contact, and task management system with JUnit tests. Refactored for the Capstone ePortfolio to eliminate architectural bottlenecks, guarantee immutability, and introduce thread-safe memory management.

Key Enhancements Implemented:

  • Centralized Validation: Replaced repeated validation checks with a dedicated validation utility module.
  • Builder Pattern: Streamlined object instantiation and enforced thread safety.
  • Algorithmic Optimization: Migrated linear search structures to thread-safe ConcurrentHashMap for $O(1)$ lookup performance.
  • Expanded Unit Testing: Refactored JUnit 5 suites to support exception handling and maintain rigorous code coverage.
