Program Experience, Strengths, and Professional Growth

Completing my coursework and assembling this ePortfolio has profoundly shaped my professional identity, helping me bridge theoretical concepts with real-world application. Throughout the program, I have cultivated a versatile skill set spanning software development across C++, Java, Python, x86-64 assembly, and SQL.

My professional goals center on building reliable, maintainable software and secure systems, underpinned by several core competencies:

  • Collaborating in a Team Environment & Communicating with Stakeholders: Software engineering is ultimately a collaborative effort. Throughout my coursework, such as simulating Agile Sprint Reviews and retrospectives for travel software projects, I learned how to align technical objectives with business requirements, coordinate team workflows, and articulate technical decisions clearly to diverse stakeholders.
  • Data Structures and Algorithms: Optimizing application performance requires a deep understanding of runtime complexity. By designing and refactoring backend data structures, transitioning from basic linear lookups to thread-safe ConcurrentHashMap implementations, binary search trees, and custom hash tables, I have learned to balance RAM efficiency with O(1) lookup performance to ensure seamless scaling under heavy loads.
  • Software Engineering and Databases: I approach software design with a focus on maintainability, scalability, and modular architecture. From designing object-oriented Java services using the Builder pattern and centralized validation utilities to establishing MongoDB database schemas, PyMongo CRUD modules, and interactive Plotly Dash web dashboards, I build applications structured for long-term growth and clean separation of concerns.
  • Security: Security is foundational to modern software development. My studies have equipped me to implement robust defensive programming practices, ranging from SHA-256 checksum verification and HTTPS SSL/TLS configurations to XOR file encryption, OWASP dependency vulnerability suppression, and strict role-based access control.
